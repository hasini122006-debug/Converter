# Binary Decimal Hexadecimal Converter (Verilog)

## Project Description

This project converts an 8-bit binary number into its Decimal and Hexadecimal equivalents.

## Features

- Binary Input (8-bit)
- Decimal Output
- Hexadecimal Output
- Simulation using Testbench

## Software Required

- Xilinx Vivado
- ModelSim
- Icarus Verilog
- GTKWave (Optional)

## Files

converter.v          -> Main Verilog Module

converter_tb.v       -> Testbench

simulation_output.txt -> Simulation Result

README.md            -> Documentation

## Input

8-bit Binary Number

## Output

Decimal Value

Hexadecimal Value

## Sample Conversion

Binary : 00001010

Decimal : 10

Hexadecimal : 0A
